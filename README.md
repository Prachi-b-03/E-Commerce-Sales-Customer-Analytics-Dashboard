# 📊 E-Commerce Sales & Customer Analytics Dashboard

## 📌 Project Overview

This is my first Excel Dashboard project, created to analyze E-Commerce sales and customer data and transform raw data into meaningful and easy-to-understand insights.

The dashboard provides an interactive overview of sales performance, profitability, customers, products, regions, sales channels and order status.

## 🎯 Project Objectives

- Analyze overall sales and profit performance
- Track important business KPIs
- Understand monthly sales and profit trends
- Compare sales performance across regions
- Analyze sales by product category
- Understand customer segments
- Compare different sales channels
- Identify the Top 10 products
- Monitor return rate and profit margin

## 📊 Key Performance Indicators

- Total Sales: ₹1.09 Cr
- Total Profit: ₹0.32 Cr
- Total Orders: 5,000
- Total Customers: 899
- Units Sold: 7,996
- Average Order Value: ₹2,181.78
- Profit Margin: 29.77%
- Return Rate: 16.22%
